## Цель работы

Обучить случайный лес, сравнить его с одиночным деревом решений, подобрать основные гиперпараметры через кросс-валидацию и проверить, можно ли удалить слабые признаки без потери качества.

## Данные

Используется табличный датасет из предыдущей работы: **120 объектов**, 6 числовых признаков (`age`, `income`, `activity_score`, `debt_ratio`, `tenure_months`, `support_calls`) и бинарный `target`.

## Что реализовано

- `DecisionTreeClassifier` и `RandomForestClassifier` на одном train/test split;
- GridSearch по `n_estimators`, `max_depth`, `min_samples_leaf`;
- 18 комбинаций параметров и 5-fold cross-validation;
- сравнение tuned Random Forest с параметрами по умолчанию;
- `feature_importances_` и диаграмма важности;
- последовательный эксперимент удаления слабых признаков;
- сохранение всех таблиц и результатов в `results/`.

## Ключевые результаты

| Модель | Accuracy | F1 | ROC AUC |
|---|---:|---:|---:|
| Decision Tree | 0.8000 | 0.6667 | 0.7619 |
| Random Forest | **0.9000** | **0.8235** | **0.9630** |

Лучшие параметры GridSearch:

```text
n_estimators = 100
max_depth = None
min_samples_leaf = 1
CV F1 = 0.7211
```

Два наиболее важных признака:

1. `income` — 0.2686;
2. `tenure_months` — 0.2189.

Эксперимент показал, что `age` и `support_calls` можно исключить вместе без потери качества: CV F1 вырос с `0.7211` до `0.7272`, а test F1 — с `0.8235` до `0.8421`.

## Ключевой вывод

Случайный лес оказался заметно устойчивее одиночного дерева. Перебор гиперпараметров показал, что 100 деревьев достаточно: увеличение до 200 не улучшило CV F1. `income` и `tenure_months` дают наибольший вклад в предсказания, а `age` и `support_calls` являются кандидатами на исключение для этого датасета.
